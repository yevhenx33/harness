# map

Map only the scope named by the user.

- trace ownership and runtime or data-flow boundaries
- identify relevant files, dependencies, contracts, and consumers
- record invariants, failure modes, security boundaries, and performance risks
- list existing tests and available coverage
- call out conflicting evidence and unresolved gaps
- remain read-only unless implementation is explicitly requested
