# github

Use this skill when a repository URL, GitHub repository, pull request, issue,
or branch is in scope.

- resolve the exact repository before acting
- inspect local status and preserve pre-existing changes
- use connector or read-only GitHub inspection for repository context
- treat commit, push, pull-request creation, and other publication as explicit
  actions requiring user intent
- report the exact local path, branch, files changed, and publication status
