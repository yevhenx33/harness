# read

Use this skill when the task is explicitly read-only or asks for a check,
map, audit, inspection, status, or report.

- do not edit files, commit, deploy, or mutate production state
- inspect only the requested scope and nearest applicable instructions
- report ownership, boundaries, invariants, tests, coverage, risks, unknowns,
  and the smallest useful implementation slices
- distinguish direct evidence from inference
- include computational and operational impact where relevant
